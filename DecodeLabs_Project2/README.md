**CryptoGuard — Basic Encryption & Decryption**

A simple web-based encryption and decryption tool developed as **Project 2 of the DecodeLabs Cyber Security Internship**.

CryptoGuard demonstrates the basic concept of **symmetric text transformation** using the Caesar Cipher, allowing users to encrypt and decrypt messages using a selectable shift key.

**Objective**

The project focuses on:

- Understanding basic encryption and decryption concepts
- Implementing the Caesar Cipher
- Using a configurable shift key
- Building a simple web-based security tool
- Understanding the limitations of basic cryptographic techniques

**Features**

- 🔒 **Encrypt Message** — Converts plain text into encrypted text.
- 🔓 **Decrypt Message** — Converts encrypted text back into readable text.
- 🔢 **Custom Shift Key** — Allows users to select a shift value from 0–25.
- 📋 **Copy Output** — Easily copy encrypted or decrypted results.
- 🧹 **Clear Input** — Quickly reset the text fields.
- 💡 **How It Works** — Provides a simple explanation of the Caesar Cipher.
